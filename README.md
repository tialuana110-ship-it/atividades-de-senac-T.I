## O que é um READ.me?
O comando READ.me, serve para criar um guia introdutivo e documentação para um projeto de software, geralmente escrito em formado Markdown (.md). o mesmo é usado para fornecer informações essenciais, como o que o projeto faz, como instala-lo e usá-lo, os requisitos necessários, as funcionalidades principais e até mesmo como os outros projetos desenvolvedores podem contribuir 

#### 💻 Comandos CMD voltados para hardware
1. **Comando:** `systeminfo`  
   **Função:** Mostra informações detalhadas sobre o sistema operacional e o hardware.  
   **Uso:** Diagnóstico geral.
